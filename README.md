# motion-expressions_in_spanish
This project examined the use of motion expressions in Spanish learners' speech samples.

## Project Overview

This repository documents a longitudinal corpus-based study of language learners' use of motion constructions, defined as associations of a form (e.g., verb + noun) with the meaning of a physical movement from one point to another in space (e.g., El chico salta la valla ‘The boy jumps over the fence’) or in the same location (e.g., El chico salta sobre la cama ‘The boy jumps on the bed’). The project examined how English-speaking learners of Spanish express motion events, focusing on form-meaning pairings such as motion, motion-ground, motion-path, and motion-path-ground constructions.  The study followed 31 university learners of Spanish across a 16-week semester. Learners completed oral production tasks at four-week intervals, producing speech data that were transcribed, segmented, and annotated for motion verbs, path and ground expressions, and construction types. The project also incorporated learner-level variables such as proficiency, language exposure, language use, and social network size.

## File descriptions

* **study_design.pdf:** Describes the study design, including research questions, participant information, data collection procedures, annotation workflow, analysis methods, and main findings.
  
* **annotation_guidelines.pdf:** Provides the annotation scheme used to code motion constructions, including coded variables, the list of motion verbs and path expressions, and examples.
  
* **sample_annotated_data.csv:** Contains a sample of annotated data, including participant ID, session number, motion clauses produced by participants, and syntactic types of motion constructions.
  
* **quality_assurance.R:** The R script evaluates inter-rater reliability between two coders for the syntactic classification of motion constructions. It calculates percent agreement and Cohen’s kappa, identifies disagreement cases, and generates a confusion matrix showing where coder labels diverged.
